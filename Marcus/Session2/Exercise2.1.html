Exercise 2.1 – Planning the Layout

We want to create a bar chart that follows the layout shown in the exercise diagram. Below are the planning questions and answers:

a) How would you create the bars using scales?

Answer:

To create the bars using scales, we use two main approaches:

1. X-axis Scale (Horizontal Positioning):

  • Use d3.scaleBand() for the date domain to allocate equal space for each date group
  • The band scale handles spacing and padding automatically
  • Within each band, offset each bar category by a fixed amount (e.g., 0, barWidth+1, 2*(barWidth+1))

2. Y-axis Scale (Vertical Positioning & Height):

  • Use d3.scaleLinear() to map search volume values to pixel heights
  • Domain: [0, max value from data]
  • Range: [innerHeight, 0] (inverted so higher values go up)
  • Bar height: innerHeight - y(value)
  • Bar y-position: y(value)

Code Pattern:

const x = d3.scaleBand()
    .domain(dates)
    .range([0, innerWidth])
    .padding(0.1);

const y = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.value)])
    .range([innerHeight, 0]);

// For grouped bars within each band:
const barWidth = x.bandwidth() / 3;  // 3 categories
chart.selectAll("rect")
    .data(data)
    .join("rect")
    .attr("x", d => x(d.date) + types.indexOf(d.type) * barWidth)
    .attr("y", d => y(d.value))
    .attr("width", barWidth - 1)
    .attr("height", d => innerHeight - y(d.value));

b) How would you position the labels using scales?

Answer:

Labels are positioned in two places:

1. Y-axis Date Labels (Left side):

  • Use the same x scale (or derived scale) to compute y-positions for each date
  • X-position: Fixed at a constant left margin (e.g., -10px from axis, for text alignment)
  • Y-position: x(date) + x.bandwidth() / 2 (center of each date band)
  • Use d3.axisLeft(y) to render the value axis automatically
  • Use D3 axis on transformed date axis to show date labels

2. X-axis Value Labels (Bottom):

  • Use d3.axisBottom(y) to show value ticks and labels
  • Positioned at y = innerHeight

3. Legend Labels:

  • Position absolute or within an SVG <g> group at fixed coordinates
  • Each label corresponds to a color and category

Code Pattern:

// Y-axis (dates on left)
const yAxis = d3.axisLeft(x)
    .tickFormat(d => d3.timeFormat("%Y-%m-%d")(d));
chart.append("g")
    .call(yAxis);

// X-axis (values at bottom)
chart.append("g")
    .attr("transform", `translate(0, ${innerHeight})`)
    .call(d3.axisBottom(y));

c) How would you use groups (<g>) to create the legend?

Answer:

SVG <g> (group) elements organize visual elements hierarchically. Use them for the legend like this:

Structure:

  • Create one main <g> for the entire legend, positioned at fixed coordinates (e.g., top-left)
  • Within that, create a separate <g> for each category
  • Each category group contains:
    • A colored <rect> (color swatch)
    • A <text> label (category name)
  • Use .attr("transform", `translate(x, y)`) to offset each item

Code Pattern:

const legend = svg.append("g")
    .attr("transform", "translate(20, 20)");  // Top-left position

const legendData = ["bar Horsens", "cafe Horsens", "pizza Horsens"];
const colors = ["#1f77b4", "#ff7f0e", "#2ca02c"];

const legendItems = legend.selectAll(".legend-item")
    .data(legendData)
    .join("g")
    .attr("class", "legend-item")
    .attr("transform", (d, i) => `translate(0, ${i * 20})`);  // Vertical spacing

legendItems.append("rect")
    .attr("width", 15)
    .attr("height", 15)
    .attr("fill", (d, i) => colors[i]);

legendItems.append("text")
    .attr("x", 20)
    .attr("y", 12)
    .text(d => d)
    .style("font-size", "12px");

Visual Layout (ASCII representation):

Legend Group (g) ├─ Legend Item 1 (g, y=0) │ ├─ rect (15x15, #1f77b4) │ └─ text "bar Horsens" (x=20) ├─ Legend Item 2 (g, y=20) │ ├─ rect (15x15, #ff7f0e) │ └─ text "cafe Horsens" (x=20) └─ Legend Item 3 (g, y=40) ├─ rect (15x15, #2ca02c) └─ text "pizza Horsens" (x=20)

Benefits of using groups:

  • Encapsulation: Related elements stay together
  • Transform inheritance: Child elements inherit group transforms
  • Easy repositioning: Move entire legend by changing group transform once
  • Scalability: Easy to add/remove legend items via data binding
